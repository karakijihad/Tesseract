Preparing first-run setup…

Used everywhere it refers to itself, and it is half of the wake phrase below. You can change it later. Something distinctive works better than an everyday word — a name that turns up in ordinary sentences is one the wake word has to hear apart from them.

The wake phrase is always two words — this one and the name above, so “hey Ada” or “ciao Sara”. Left blank it stays “hey”. Nothing to record here: the app answers everything until you say the phrase once in Settings → Voice and watch it land. What you record there is checked on this machine and discarded — no audio is stored or uploaded, and a muted microphone is muted.

Voice

Filters the voice list. Nothing can speak yet — the voices arrive with this install — so once setup finishes, Settings → Voice lists them all and plays the one you have selected. A cloud voice is listed there whether or not you added its key, and says which key it needs.

API keys

All optional, and all addable later in Settings → API keys. Without a chat key it still listens, remembers and searches your own files — it just has nothing to answer with.

Optional

Anything you skip downloads nothing at all. Each one can be added afterwards from Settings.
